How to Use the Web InterfaceCreate a Quick Note: Click the Take a note... input box at the top to expand the text field.Add a Title & Options: Type your headers in the Title field and toggle options like reminders, colors, or archives using the toolbar icons.Save/Close Notes: Click the Close button on an open form to commit your inputs.Navigate Categories: Use the left Sidebar to switch views between Notes, Reminders, Archive, and Trash.Edit Existing Notes: Click directly on any rendered note card in the main grid layout to open the editing Modal view.
